# 真实闲鱼账号校准

真实联调必须由用户在“浏览器连接”页面主动开启。

1. 在可见独立浏览器中扫码登录。
2. 登录后停留至少 30 秒并打开个人页，确认可见账号名称。
3. 正常关闭独立浏览器，再由账号中心使用同一 Profile 启动；账号仍在线才算扫码流程通过。
4. 在工作台生成一次性配对码并连接扩展，然后只读识别登录、商品、消息、订单和交付页面。
5. 停留在发布页，检查扩展报告的页面类型、页面地址、标签页、适配器版本和 DOM 指纹。
6. 只填充一件测试商品草稿，不提交。
7. 人工复核标题、详情、价格和六图后，另行输入明确确认，才允许单件提交。
8. 使用事先准备的受控测试买家完成咨询、付款和附件交付。
9. 中途重启工作台，确认不会重复发送。
10. 分别测试退款、投诉、验证、违规、范围不清和结果未知的停机行为。

所有步骤通过前，不开放真实自动化放量，不使用第一位真实买家做试验。
