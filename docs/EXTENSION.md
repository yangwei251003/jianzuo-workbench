# 简作连接助手安装与配对

1. 用工作台“账号中心”点击“打开模拟闲鱼”或“打开真实闲鱼扫码页”。独立浏览器会自动使用项目下的 `apps/extension`。
2. 如果需要手动安装，在 Chrome/Edge 打开扩展管理页，开启开发者模式，选择“加载已解压的扩展程序”，目录选 `apps/extension`。
3. 在工作台生成六位配对码，在扩展弹窗输入。
4. 状态显示“已连接本地工作台”后，先在模拟站训练。

扩展权限只有 `storage`、`activeTab`、`scripting` 和 `alarms`，清单中没有 `cookies`。配对令牌通过 WebSocket 第一帧传输，不出现在 URL 和服务器访问日志中。令牌默认 8 小时有效；过期或被新配对替换后，扩展会清除旧令牌并明确提示重新配对，不会无限重连旧令牌。

真实页面 DOM 变化、验证码、人脸、滑块、输入框不唯一或提交结果不明时，扩展会停止并返回人工接管。
