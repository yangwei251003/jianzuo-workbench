# 安全模型

## 信任边界

- 浏览器 Profile 保存登录状态，但不进入数据库、日志或备份。
- 扩展不申请 `cookies` 权限，只读取页面正常可见内容。
- 本地 PIN 通过 scrypt 派生；敏感设置采用 AES-256-GCM。
- 客户可识别文件发送给 Codex 前必须记录单独同意，撤回后停止后续处理。

## 强制停机

退款、投诉/法律威胁、验证码/人脸/滑块、违规需求、范围/价格不清、页面结构变化或外部结果未知均失败关闭。全局紧急停止会暂停 Worker、Outbox 与扩展写动作，只保留只读查看。

## 保留期

- 原客户文件：30 天。
- 交付物：90 天。
- 聊天和订单：180 天。
- 审计：1 年。
- 加密备份：7 个日备、4 个周备；排除浏览器 Profile 与 Codex 凭据。
