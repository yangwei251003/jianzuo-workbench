# 06｜备份、恢复与常见故障处理

这一册用于保护本地数据，并在启动、登录、扩展、Codex 或任务出现异常时安全处理。

## 当前状态

- **已可用**：手动加密备份、托盘安全恢复向导、命令行恢复、任务租约恢复、日志轮转、紧急停止和脱敏审计。
- **已验证**：重启后持久任务不会丢失；真实浏览器动作结果不明时进入 `RESULT_UNKNOWN`，不会自动重放。
- **已验证**：专用浏览器使用同一 Profile 完全关闭并重启后，真实闲鱼登录仍能复用。
- **已验证**：恢复会先在暂存区完成解密、哈希、路径和数据库完整性检查；提交中途失败时，原数据库、WAL/SHM 和已覆盖产物会自动回滚。故障注入测试不会接触生产数据。
- **仍需注意**：浏览器 Profile 不在备份中，恢复数据库或迁移电脑不会自动恢复闲鱼登录。
- **尚未提供**：无需人工确认的一键恢复、正式安装包和自动更新。可选开机自启已提供并默认关闭，操作方法见第 01 册。

## 创建加密备份

### 在工作台里备份

1. 左侧进入“设置与安全”。
2. 找到“加密备份”。
3. 输入当前本地 PIN。
4. 点击“立即备份”。
5. 记下页面反馈中的 `.jzb` 文件路径。
6. 把备份复制到安全位置，但不要与 PIN 保存在同一处。

### 使用备份脚本

在项目文件夹打开终端，运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/backup.ps1
```

按提示输入当前 PIN。输入时不会显示明文。备份默认保存在项目的 `data\backups` 下。

## 备份包含和不包含什么

备份用于保存数据库和受控业务数据。它**不包含**：

- 闲鱼专用浏览器 Profile；
- 浏览器 Cookie 或登录凭据；
- Codex/ChatGPT 登录凭据；
- 密码、验证码或远控码。

因此，换电脑或恢复备份后，闲鱼和 Codex 可能需要重新由你本人登录。

系统目标保留 7 个日备和 4 个周备。原客户文件、交付物、聊天订单和审计记录还有各自的自动清理期限，可在“设置与安全”查看。

## 恢复备份

恢复会替换当前数据库，操作前务必谨慎。

1. 如果当前工作台还有重要新数据，先创建一份新的备份。
2. 关闭正在进行的商品发布、消息或交付操作。
3. 在 Windows 托盘中右键“简作”，选择“恢复加密备份（安全向导）”。系统会显式打开一个 PowerShell 窗口；恢复不会在后台静默执行。
4. 如果托盘不可用，也可以在项目文件夹打开终端，运行：

   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts/restore.ps1
   ```

5. 选择或输入要恢复的 `.jzb` 文件完整路径。向导会先确认它存在、是文件且扩展名正确，并只允许固定数据库文件作为恢复目标；项目根目录、目录和 `data\browser-profile` 均不能成为目标。
6. 脚本要求确认时，准确输入 `RESTORE`。
7. 输入创建该备份时使用的本地 PIN。PIN 使用安全输入，不会写入文件、日志或命令行。
8. 向导会停止核心服务，再调用现有受控恢复程序。该程序会先创建一份 `manual` 保护备份。
9. 等待出现“恢复完成”。成功后核心服务保持停止，请关闭向导窗口并双击桌面的“启动简作闲鱼工作台”。
10. 检查商品、内容版本、订单、任务和设置是否符合备份时间点。

如果恢复失败，向导会显示明确错误；受控恢复程序会先自动回滚本次替换，若恢复前核心服务正常运行，还会在清理 PIN 后尝试重新启动原服务。不要连续重复恢复，先按窗口提示人工检查。若提示“自动回滚未完全成功”，不要删除窗口给出的保留目录，应保留现场并人工处理。

不要把扩展名改成 `.jzb` 来冒充备份，也不要在恢复过程中强制关机。

## 全局紧急停止

遇到账号不对、页面变化、重复动作风险或任何不确定情况：

1. 点击左侧底部“紧急停止”，或进入“设置与安全”；
2. 确认顶部出现“写操作暂停”；
3. 工作台仍可查看数据，但 Worker、Outbox 和扩展不会开始新的写操作；
4. 查清问题后，由你点击“人工确认并恢复”。

恢复后，`RESULT_UNKNOWN` 动作仍不会自动重放，这是正常的安全保护。

## 常见故障处理

### 工作台打不开

1. 双击“停止简作闲鱼工作台”；
2. 等待几秒，再双击启动；
3. 仍失败时查看：
   - `<home>\Desktop\闲鱼工作台\data\logs\workbench.err.log`
   - `<home>\Desktop\闲鱼工作台\data\logs\workbench.out.log`
4. 日志超过一定大小会自动轮转为 `.1` 到 `.5`。

不要把包含客户信息的完整日志发给第三方；先截取与错误时间相邻且已脱敏的部分。

### PIN 输错或暂时被锁

连续多次输错会进入短暂锁定。停止反复尝试，等待约 60 秒后再输入正确 PIN。不要通过删除数据库来绕过 PIN。

### 专用浏览器又显示二维码

本机曾通过 Profile 重启复用；如果后来又出现二维码，通常表示会话已过期、平台要求重新验证或浏览器资料发生变化。由你本人重新扫码并停留至少 30 秒，再打开个人页并执行一次正常关闭/重启测试。不要复制普通 Edge 的 Cookie 或 Profile。

### 扩展离线或过期

在“账号中心”重新生成配对码，并在 5 分钟内输入“简作连接助手”。如果图标消失，按第 02 册重新加载扩展。

### 出现验证码、人脸或滑块

保持写操作暂停，由你本人在可见浏览器中完成验证。工作台不会也不应绕过验证。

### Codex 显示未启动或待登录

1. 进入“Codex 任务”；
2. 刷新状态；
3. 如显示待登录，由你点击“使用 ChatGPT 登录”；
4. 如 Codex 不可用，本地文案和模板图片仍可运行，但 AI 案例图和制作任务会等待。

### 动作显示 `RESULT_UNKNOWN`

不要批准重试，也不要重新创建相同动作。先到真实闲鱼页面人工确认发布、消息或交付到底有没有成功，再记录处理结果。未知结果自动重发可能造成重复商品、重复消息或重复交付。

### Worker 任务失败或停在队列

进入“系统运维”，查看：

- `Action Outbox`：外部动作及结果；
- `Worker 任务`：后台任务、尝试次数和状态；
- `审计记录`：谁在什么时候做了什么。

普通本地任务可以按系统策略恢复；真实浏览器动作一旦结果不明，只能人工处理。

### 真实经营数据为空

真实数据不会由演示数据补齐。完成扩展配对并打开真实商品、消息或订单页面后，工作台才会保存页面可见数字快照。未采集到的数据保持为零或空。

## 数据保留与隐私

- 原客户文件：30 天；
- 交付物：90 天；
- 聊天和订单：180 天；
- 审计记录：1 年。

客户撤回数据处理同意后，应停止把其文件交给 Codex，并按适用流程清理。浏览器登录资料不会写入数据库、日志或备份。

## 需要你手动确认的环节

- 妥善保存 PIN 和 `.jzb` 备份；
- 恢复前确认备份文件、时间点和替换当前数据库的后果；
- 对验证码、账号验证和 `RESULT_UNKNOWN` 作人工判断；
- 恢复工作台写操作前，确认账号、页面和待执行动作都正确；
- 恢复后重新登录闲鱼或 Codex（如需要）。
