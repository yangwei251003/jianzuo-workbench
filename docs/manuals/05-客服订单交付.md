# 05｜客服草稿、订单制作与数字交付

这一册讲消息、报价、订单推进、数字打包和远程服务记录。

## 当前状态

- **模拟可用**：回复建议、10% 议价底线、材料追问、风险接管、模拟消息发送、演示订单、固定数字商品打包和模拟交付。
- **已实现**：当前真实会话的唯一可见目标采集；订单目标数据契约、安全闸门和隔离页面夹具；受控回复与交付审批；数字 ZIP 校验；百度官方 OAuth 与上传后人工贴链。
- **仍需真实校准**：卖家订单聚焦本轮已改为打开“我卖出的”只读视图，但真实订单专属适配和唯一订单目标尚未使用受控测试订单实机通过；真实测试买家会话、平台附件和百度真实授权/上传也尚未执行。
- **不会自动放量**：只有完成单件发布校准后才允许创建受控真实回复或交付；完成一次测试也不会自动开启生产自动化。

## 三层安全闸门

真实回复和交付必须同时通过三层检查：

1. **店铺阶段**：账号已由你确认，并完成受控单件发布；
2. **当前目标**：专用浏览器正打开唯一的测试会话或订单，账号、商品、页面和目标指纹与采集记录一致；
3. **当次动作**：你核对内容后批准，系统在派发和回执时再次检查目标；不一致或结果未知立即停止。

三层闸门不会读取 Cookie，也不绕过验证码、人脸或滑块。`RESULT_UNKNOWN` 不会自动重放。

## 客服：先在模拟站生成草稿

1. 左侧进入“消息客服”。
2. 在“最近会话”选择一个演示会话。
3. 点击“生成回复建议”。
4. 检查系统给出的意图、置信度、依据和待补材料。
5. 修改回复，使它简短、具体、像真人说明，不作无依据承诺。
6. 训练阶段把“发送到”保持为“模拟闲鱼”。
7. 点击“发送”，再检查消息是否只出现一次。

规则优先于 AI：

- 最多优惠 10%，不得越过最低成交价；
- 材料不齐先追问，不直接承诺价格和工期；
- 需求范围变化时重新报价；
- 基础/标准/进阶分别含 1/2/3 次同范围修改；
- 人工接管时间为 09:00–22:00，系统可以全天登记需求。

## 受控真实回复

完成第 04 册的单件发布后，再准备一个受控测试买家：

1. 让测试买家向已发布的测试商品发送一条普通 FAQ；
2. 在专用浏览器打开这一位买家的具体聊天，避免同时打开多个候选会话；
3. 回到“消息客服”，在“采集当前真实会话”选择对应商品，确认页面确实是受控测试买家后执行采集；
4. 选择新采集的会话，点击“生成回复建议”；
5. 核对商品、可见目标、最新入站消息、价格、材料和回复正文；
6. 只准备一条低风险回复，由你批准后发送；
7. 重启工作台并重新打开会话，确认没有重复发送。

如果系统不能提取唯一目标、当前页面已切换、指纹不一致或最新消息发生变化，动作会停止。不要反复批准，也不要使用第一位普通真实买家测试。

## 必须立即转人工的消息

出现以下任一情况，停止 AI 回复：

- 退款；
- 投诉或法律威胁；
- 账号验证；
- 侵权、破解、造假、非法代理等违规需求；
- 定制范围或价格不清；
- 外部操作结果未知。

人工回复后，AI 会保持暂停。只有你看完上下文并确认风险已经解除，才点击“人工确认后恢复”。退款永远由人工执行。

## 订单的标准推进方式

在“订单与交付”选择演示订单，按实际情况推进：

`新订单 → 待补材料 → 可开工 → 制作中 → 待审阅 → 可交付 → 交付中 → 已交付`

如果买家申请退款，使用“转退款人工审核”，不要自动退款。不要为了让状态好看而跳过材料、审阅或送达确认。

## 客户文件交给 Codex 前

可识别的客户文件不能直接发送给 Codex。必须：

1. 向买家说明处理目的、文件范围、保留时间以及可能发生的数据跨境；
2. 取得单独、明确的同意；
3. 在订单页勾选“我已向买家展示告知，并取得单独明确同意”；
4. 点击“记录同意”；
5. 买家撤回时立即点击“记录撤回”，停止后续外部处理。

不要把密码、验证码、远控码、Cookie 或与订单无关的完整隐私信息交给 Codex。

## 固定数字商品打包

1. 选择固定数字商品的演示订单。
2. 确认成品、说明和许可证信息完整。
3. 点击“生成并校验 ZIP”。
4. 检查交付包至少包含：

   ```text
   01_成品或程序
   02_使用说明_README
   03_安装与启动方法
   04_常见问题_FAQ
   05_LICENSE与原作者声明
   06_二次修改说明
   07_版本记录与售后范围
   SHA256SUMS.txt
   ```

5. 训练阶段把“交付到”保持为“模拟闲鱼”。
6. 点击“准备发送”，再批准模拟发送。
7. 确认状态只推进一次，没有重复交付。

大文件可粘贴 HTTPS 分享链接。配置百度官方 OAuth 后，可由你确认上传 ZIP；上传完成只进入“等待粘贴链接”，个人账号自动分享不作承诺。

## 半定制商品

1. 先把材料和验收标准收完整；
2. 记录买家选择的套餐、截止时间和允许修改次数；
3. Codex 可以协助制作，但成果必须人工检查；
4. 买家提出范围外修改时重新报价；
5. 确认成品可交付后再打包。

## 远程电脑服务

远程服务始终由人工操作，工作台不自动控制买家电脑。

订单页只记录：

- 买家授权的处理范围；
- 开始和结束时间；
- 执行过的动作摘要；
- 处理结果和后续建议。

不要录屏，不保存密码、验证码或远控码。涉及超出授权范围的操作，必须再次取得买家同意。

## 受控真实订单与交付

只在上面的低风险测试回复通过后继续：

当前这部分仍是待校准流程。“我卖出的”只读视图能够打开，不表示工作台已经可靠识别订单、买家、商品和金额；没有识别出唯一订单目标时必须停止，不能创建真实交付动作。

1. 使用同一受控测试买家创建测试订单，不使用真实客户订单；
2. 从账号中心聚焦卖家订单，确认专用浏览器打开的是“我卖出的”只读视图，再进入具体受控测试订单；
3. 只有工作台能够从该真实页面识别唯一订单目标时，才在“订单与交付”选择已采集会话、套餐和服务类型并确认采集；识别失败时停止并等待专属适配更新；
4. 先用模拟连接器完整跑一遍订单、打包和交付；
5. 为无隐私、可重复验证的固定数字商品生成并校验 ZIP；
6. 小文件优先校准平台附件；大文件可在设置页完成百度授权，再勾选确认上传；
7. 百度上传后由你在百度网盘创建分享链接，把 HTTPS 链接粘贴回订单；
8. 核对订单目标、金额、交付包和链接后，准备并批准一次受控测试交付；
9. 重启工作台，确认没有重复交付。

真实测试订单及其订单目标采集尚未执行。只有专属适配、全部步骤和异常停机都通过后，才能讨论逐步放量；系统不会自动进入生产模式。

## 需要你手动确认的环节

- 修改并批准客服回复；
- 判断范围、价格和材料是否清楚；
- 记录客户数据处理同意或撤回；
- 人工检查定制成果和 ZIP；
- 提供或核对大文件分享链接；
- 采集并核对当前可见测试会话和测试订单；
- 批准一条真实低风险回复和一次受控测试交付；
- 完成远程服务并记录结果；
- 处理退款、投诉、验证和所有未知结果。
