# 02｜闲鱼账号扫码与“简作连接助手”配对

这一册用于把工作台、专用浏览器和你的单个闲鱼账号连接起来。

## 当前状态

- **已可用**：打开独立 Edge/Chrome 资料目录、显示闲鱼二维码、扩展配对、页面识别、心跳和只读数据回传。
- **已验证**：专用 Edge 已登录并识别到个人中心；完全关闭后用同一 Profile 重启仍保持登录；扩展清单没有 `cookies` 权限。
- **本机已通过**：真实个人页只读识别、扩展一次性配对与持续心跳、同一 Profile 关闭后重启复用。
- **仍需你确认**：在账号中心核对当前可见账号，并由你本人点击“确认并绑定此账号”。浏览器或工作台离线超过 8 小时时需要重新配对。

普通 Edge 已经登录闲鱼，不代表工作台的专用浏览器也已登录。两者使用不同的浏览器资料目录，这是为了隔离账号数据。

## 第一步：打开专用浏览器

1. 启动并解锁工作台。
2. 左侧进入“账号中心”。
3. “专用浏览器”优先选择 `Microsoft Edge`。
4. 在“开始真实账号校准”区域勾选“我确认现在开始真实账号校准”。
5. 点击“打开真实闲鱼扫码页”。

此操作只打开可见浏览器，不会发布商品、发送消息或发货。

## 第二步：配对浏览器扩展

专用浏览器正常会自动加载“简作连接助手”。如果扩展图标没有显示：

1. 点击浏览器右上角的扩展图标；
2. 找到“简作连接助手”；
3. 可以把它固定到工具栏，方便查看状态。

首次使用或令牌过期时完成配对：

1. 回到工作台“账号中心”；
2. 点击“生成配对码”；
3. 在 5 分钟内点击“一键连接扩展”；工作台只把这一次的 6 位码交给当前专用浏览器中的扩展，长期令牌仍只写入扩展本地存储；
4. 如果页面提示没有检测到扩展，再打开“简作连接助手”弹窗并手工输入同一个 6 位码；
5. 等待页面或扩展显示“已连接本地工作台”；
6. 确认“连接器”显示在线，配对区域显示扩展已配对。

配对令牌保持 8 小时短期有效期；扩展在线且持续发送认证心跳时会滚动续期，因此正常 24×7 运行不会因为固定时刻突然掉线。浏览器、电脑或工作台断开超过 8 小时后必须重新生成配对码。配对码和令牌不要发给其他人。

### 扩展没有自动加载时

1. 在专用 Edge 地址栏打开 `edge://extensions`；
2. 开启“开发人员模式”；
3. 点击“加载解压缩的扩展”；
4. 选择：`<home>\Desktop\闲鱼工作台\apps\extension`；
5. 回到上面的配对步骤。

扩展只使用页面正常可见的信息，不读取浏览器 Cookie，也不会导出登录凭据。

## 第三步：扫码并确认账号

1. 在专用浏览器的闲鱼登录窗口中，用手机闲鱼扫码。
2. 按手机闲鱼上的提示，由你本人确认登录。
3. 登录成功后，不要立刻关闭浏览器；停留至少 30 秒。
4. 打开闲鱼个人页，确认页面上显示的是你准备运营的账号。
5. 回到工作台“账号中心”，检查“可见账号”是否与网页一致。
6. 只有确认无误后，点击“确认并绑定此账号”。

如果出现验证码、滑块、人脸验证或账号安全确认，必须由你本人在浏览器中处理。工作台会暂停写操作，不会尝试绕过。

## 第四步：验证登录能否复用

本轮已经通过一次，后续升级浏览器或迁移电脑时仍建议复测。

1. 登录后保持在线至少 30 秒，并打开一次个人页。
2. 在“账号中心”点击“停止浏览器”，正常关闭专用浏览器。
3. 等待几秒，再由“账号中心”重新打开真实闲鱼。
4. 这次先不要扫码，查看是否仍显示已登录账号。
5. 回到工作台，确认：
   - “可见账号”仍正确；
   - “连接器”重新变为在线；
   - 页面绑定地址和最近心跳已更新。

启动器会记录这个专用 Profile 的真实浏览器根进程；即使 Edge 把新标签页交给已有进程，“停止浏览器”也只会按该完整 Profile 路径关闭，不会按浏览器名称误关普通 Edge。

只有以上全部通过，才能把“扫码登录并复用同一 Profile”记为完成。若又出现二维码，说明登录复用仍未通过：重新扫码、停留更久后再测，并继续保持真实写操作关闭。

## 配对成功后的只读检查

在“账号中心”依次点击：

- “打开前台”；
- “聚焦聊天”；
- “聚焦发布页”；
- “聚焦订单”；
- 输入商品编号后“聚焦商品”。

每次只检查页面能否打开、工作台能否识别页面类型和更新时间。不要在真实页面发送消息、提交商品或确认发货。

消息和订单页还会显示“当前可见目标”信息。这里的采集只读取当前页面，不会发送消息或交付；必须等第 05 册准备好受控测试买家后再绑定，不能把普通真实买家当测试对象。

## 需要你手动确认的环节

- 手机扫码及手机端确认登录；
- 核对网页上显示的闲鱼账号；
- 点击“确认并绑定此账号”；
- 任何验证码、人脸、滑块或安全验证；
- 关闭并重启后确认账号是否仍在线。

## 常见问题

- **工作台显示“等待配对”**：重新生成配对码，并在 5 分钟内输入扩展。
- **扩展提示令牌过期**：重新配对，不要重复使用旧码。
- **一键连接提示未检测到扩展**：刷新当前工作台页面；仍失败时打开扩展弹窗，手工输入页面上的 6 位码。
- **网页已登录但工作台看不到账号**：确认当前窗口是工作台启动的专用浏览器，并检查扩展是否在线。
- **普通 Edge 已登录，专用浏览器仍要扫码**：这是正常隔离，不要复制 Cookie 或浏览器资料。
- **工作台显示“需要人工处理”**：停止自动操作，在浏览器中处理验证或页面变化后再恢复。
