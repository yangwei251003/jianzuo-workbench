# 03｜准备商品、白描文案与六张商品图

这一册讲怎样从 24 个首发商品中选择一个，生成可检查的发布内容包。

## 当前状态

- **已可用**：24 个商品的三档价格、最低成交价、服务范围、材料清单、FAQ、交付规则、合规边界和六图计划。
- **已可用**：逐商品策划规则模板生成白描文案；五张含中文、价格和流程的图片由本地模板生成。
- **已实现但尚未实机产出**：Codex 可生成独立文案候选；工作台会验路径、JSON 结构、价格、禁词和事实声明，展示规则基线与 AI 候选差异，再由你二次确认是否接受为新版本。当前尚未实际生成并接受首份候选。
- **模拟可用**：完整内容包和商品图可以进入模拟发布流程。
- **已实现**：Codex ImageGen 先生成独立候选文件，工作台检查目录、PNG、尺寸、大小和 SHA-256 后才会替换第 2 张图；失败时保留本地模板。
- **仍需人工验收**：24 件商品尚未逐一真实生成案例图并人工验图；未验图的本地案例图只能视为结构示意。

## 选择商品

1. 左侧进入“商品库”。
2. 用分类或搜索找到商品。
3. 查看三档价格、最低成交价、计划发布日和准备状态。
4. 点击该行右侧“策划”，进入“内容工厂”。

价格规则已经固定：最低成交价为标价的 90%，基础/标准/进阶分别包含 1/2/3 次同范围修改。不要为了成交手工承诺更低价格或无限修改。

## 生成完整内容

如果要先把首发商品全部准备好，可以在“内容工厂”顶部点击“检查并补齐全部内容”。系统会逐项准备 24 个商品的白描文案和六图模板，并显示已就绪、待准备、失败原因和逐项结果。已有且校验通过的版本不会重复生成；这个批量动作不会调用 ImageGen，也不会创建发布任务。

只准备当前商品时：

1. 在“内容工厂”确认当前商品正确。
2. 点击“生成完整内容”。已有版本时，按钮会变成“生成新版本”。
3. 等待页面出现版本号和校验状态。
4. 按四个页签逐项检查：
   - “标题与文案”；
   - “六张商品图”；
   - “材料与 FAQ”；
   - “交付与合规”。

系统会用当前商品的策划规则模板生成三个标题候选，并选出一个默认标题。详情采用短句、具体说明和真实起价，不使用夸张承诺、假案例或虚构资历。这里的“生成”是确定性的本地规则生成，不表示已经调用 Codex 或其它 AI 模型。

如需 AI 改写，在“Codex 白描改写”中依次点击“让 Codex 改写”“检查候选”。验真通过后先逐项比较规则基线与 AI 候选；只有勾选“我已逐项核对”并再次点击接受，才会创建新内容版本并重渲染六图。也可以明确拒绝候选并继续使用规则版。任务提交或文件出现都不等于已经验真、接受或发布。

## 六张图分别做什么

1. **品牌封面**：商品名称和核心服务；
2. **案例效果**：该商品的真实结构示意或经人工检查的 AI 案例图；
3. **价格范围**：基础、标准、进阶三档价格与范围；
4. **服务流程**：买家咨询、补材料、制作、确认和交付；
5. **材料清单**：买家下单前要准备的文件与说明；
6. **修改售后**：修改次数、售后范围和明确不接的需求。

除第 2 张案例图外，其余五张图优先使用本地模板。这样可以避免 AI 把中文、价格、修改次数或流程写错。

## 使用 Codex 重做案例图

没有 API Key 也可以尝试使用本机 Codex：

1. 左侧进入“Codex 任务”；
2. 确认状态为“已就绪”；如显示待登录，由你本人点击“使用 ChatGPT 登录”；
3. 返回“内容工厂”的“六张商品图”；
4. 点击“让 Codex 生成案例图”；
5. Codex 完成后点击“检查生成成品”；
6. 只有页面显示“已验真替换”，第 2 张图才已经更新；
7. 逐张人工检查后，才允许用于真实发布。

额度不足、Codex 未登录或生成失败时，工作台会保留本地示意图，不应把示意图说成真实客户案例。

## 发布前人工检查表

### 标题与文案

- 商品名、起价和服务范围一致；
- 没有“保证效果”“全网最低”“百分百”等无依据承诺；
- 没有“赋能”“一站式解决”等空泛套话；
- 没有声称纯手工、虚构资历或盗用第三方原创。

### 价格与材料

- 三档价格与商品库一致；
- 最低成交价没有低于标价的 90%；
- 材料清单能让买家在下单前准备完整；
- 定制范围不清时写明“看完材料再报价”。

### 六张图

- 正好六张，顺序正确；
- 中文、数字和价格可以清楚阅读；
- 案例图没有虚构真实客户结果；
- 图片不包含客户隐私、未授权素材或侵权内容。

### 合规与交付

- “交付与合规”页没有许可证或禁词阻断；
- 数字商品说明交付内容和使用方式；
- 远程服务明确为人工执行，不承诺自动远控；
- 侵权去水印、凭证造假、破解、非法代理等需求明确拒绝。

## 需要你手动确认的环节

- 检查并选择最终标题；
- 核对三档价格和服务范围；
- 检查 AI 案例图是否真实、合规、无乱码；
- 确认材料清单足以完成订单；
- 确认内容包显示“校验通过”或处理完全部复核问题。

内容生成完成不等于已经发布。下一步按第 04 册先做模拟发布，再做真实“只填草稿”校准。
