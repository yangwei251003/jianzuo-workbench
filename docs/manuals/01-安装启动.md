# 01｜安装、启动与第一次进入

这一本只讲怎样把“简作 · 闲鱼 AI 运营工作台”在当前 Windows 电脑上运行起来。

## 当前状态

- **已可用**：本地工作台、系统托盘、一键启动/停止、桌面快捷方式、可选开机自启、本地 PIN、SQLite 数据库和后台任务队列。
- **已验证**：工作台只监听本机 `127.0.0.1`，同一局域网的其他设备不能直接访问。
- **尚未提供**：正式安装包和自动更新。当前版本从项目目录安装和启动。

## 安装前准备

电脑需要具备：

1. Windows 10 或 Windows 11；
2. Node.js 24 或更高版本；
3. pnpm 10 或更高版本；
4. Microsoft Edge 或 Google Chrome。

不需要 Docker。没有 API Key 也能启动。只有使用 AI 文案、AI 案例图或 Codex 制作任务时，才需要本机 Codex 已安装并登录 ChatGPT。

## 第一次安装

1. 打开项目文件夹：`<home>\Desktop\闲鱼工作台`。
2. 在文件夹空白处右键，选择“在终端中打开”。
3. 粘贴并运行：

   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts/setup.ps1
   ```

4. 等待出现“安装完成”的提示。安装过程会自动检查、构建程序并创建数据目录。
5. 回到桌面，确认出现两个快捷方式：
   - `启动简作闲鱼工作台`
   - `停止简作闲鱼工作台`

安装完成后，开机自启默认保持关闭。只有你从托盘菜单或管理脚本明确启用后，它才会生效。

安装脚本不会删除已有的 `data` 数据目录。以后重新安装或升级前，仍建议先按第 06 册创建一次加密备份。

## 第一次启动

1. 双击桌面的“启动简作闲鱼工作台”。
2. 等待工作台窗口出现。首次启动可能比平时稍慢。
3. 设置一个 **6–12 位数字 PIN**。
4. 记住这个 PIN。它用于解锁工作台和加密备份，工作台不会替你显示原 PIN。
5. 进入后先看顶部三个状态：
   - “闲鱼”：真实账号是否在线；
   - “连接器”：浏览器扩展是否在线；
   - “Codex”：本机 Codex 是否就绪。

第一次看到“离线”或“未启动”是正常的。工作台本体启动成功，不等于真实闲鱼账号和 Codex 已经连接。

## 日常启动和停止

日常启动：双击“启动简作闲鱼工作台”。

关闭工作台窗口时，程序通常会隐藏到系统托盘，并不等于完全停止。需要彻底停止时，用以下任一方式：

- 在系统托盘中选择退出/停止；
- 双击桌面的“停止简作闲鱼工作台”。

停止会关闭工作台服务和它启动的专用浏览器，但保留数据库、商品内容和专用浏览器资料。

## 可选开机自启

开机自启默认关闭，也不会在安装或升级时自动打开。需要使用时：

1. 先启动简作工作台；
2. 在 Windows 系统托盘中右键“简作”；
3. 选择“启用开机自启”；
4. 看到“已启用开机自启”的反馈后即设置完成。

关闭时，在同一菜单选择“关闭开机自启”。托盘菜单会显示“已启用”“已关闭”或“需要处理”等当前状态。

这项设置只会在当前 Windows 用户的 Startup 文件夹中创建一个固定名称的快捷方式。快捷方式指向本项目现有的 `scripts/start-desktop.ps1`，不会复制 PIN、账号凭据、Cookie 或专用浏览器资料，也不需要管理员权限。

如果托盘暂时不能使用，也可以在项目文件夹中打开终端，运行独立管理脚本：

```powershell
# 查看状态
powershell -ExecutionPolicy Bypass -File scripts/manage-startup.ps1 -Action Status

# 启用
powershell -ExecutionPolicy Bypass -File scripts/manage-startup.ps1 -Action Enable

# 关闭
powershell -ExecutionPolicy Bypass -File scripts/manage-startup.ps1 -Action Disable
```

移动或重命名项目文件夹前，建议先关闭开机自启；移动完成后再从新位置启用。如果菜单显示“需要处理”，先选择“关闭开机自启”，再重新启用。

## 怎样判断启动成功

满足以下三项即可认为工作台本体已正常启动：

1. 能看到 PIN 解锁页或工作台首页；
2. 页面顶部显示 `127.0.0.1`；
3. “经营总览”“商品库”“内容工厂”等左侧菜单可以打开。

真实闲鱼功能还要继续完成第 02 册的扫码和扩展配对，不能只凭工作台能打开就认定真实自动化已经可用。

## 需要你手动确认的环节

- Windows 首次运行脚本时如出现安全提示，请确认路径确实是本项目的 `scripts/setup.ps1` 后再允许。
- 第一次进入时必须由你本人设置并保存 PIN。
- 工作台不会替你处理闲鱼验证码、人脸或滑块验证。

## 快速排查

- **双击后没有窗口**：先等 20 秒，再看系统托盘是否已有“简作”。
- **提示缺少 Node.js 或 pnpm**：先安装提示中的最低版本，再重新运行安装脚本。
- **页面打不开**：先双击“停止简作闲鱼工作台”，再重新启动；仍失败时查看第 06 册。
- **忘记 PIN**：不要删除数据库或反复试错。连续输错会短暂锁定；应先找回记录，再按第 06 册处理。
