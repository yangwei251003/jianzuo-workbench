## 唯一的真实操作顺序

`确认并绑定账号 → 准备受控测试买家 → 一件商品只填草稿 → 用户确认单件发布 → 打开测试会话并采集可见目标 → 生成、核对并批准回复 → 采集测试订单 → 先模拟交付再制作固定数字包 → 用户确认受控交付`

卖家订单聚焦目前只负责打开“我卖出的”只读视图。真实订单专属适配和唯一订单目标仍须通过受控测试订单实机校准；识别失败时应停止，不能继续真实交付。

百度上传成功后仍要由用户创建并粘贴 HTTPS 分享链接。任何验证、投诉、退款、违规需求、范围不清或结果未知都会停止自动写操作；退款永远人工执行。
