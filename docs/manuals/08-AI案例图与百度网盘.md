# 08｜AI 案例图验真与百度网盘大文件

本册说明两个可选能力：使用本机 Codex / ChatGPT 登录生成并验真商品案例图，以及把过大的数字交付包上传到百度网盘。两项都不是工作台启动的前置条件；没有 API Key、没有 ImageGen 额度或没有百度开放平台配置时，本地商品模板、打包和人工粘贴 HTTPS 链接仍可使用。

## 当前状态

- **已验证**：本机 Codex 已读取现有 ChatGPT 登录并进入 `ready`，无需手工配置 API Key 即可使用 Codex 主路径。
- **已实现并有隔离测试**：ImageGen 候选文件验真、百度 OAuth state/PKCE、官方主机限制、分片上传、超时和日志脱敏。
- **尚未实机完成**：24 张案例图没有逐件真实生成并人工验图；没有使用真实百度开放平台应用完成授权或上传。
- **固定降级**：ImageGen 不可用时保留本地结构示意图；百度个人账号不能自动分享时等待用户粘贴 HTTPS 链接。

## 一、生成并验收 AI 案例图

1. 打开“内容工厂”，选择一个已经生成完整内容包的商品。
2. 切到“六张商品图”。第 2 张默认是本地结构示意，不会冒充真实客户案例。
3. 点击“让 Codex 生成案例图”。工作台会使用当前 Codex 的 ChatGPT 登录，把候选图写入新的文件，验真前不覆盖模板。
4. 等 Codex 任务完成后，点击“检查生成成品”。
5. 只有路径、PNG 解码、尺寸、文件大小和前后 SHA-256 都通过时，候选图才会原子替换第 2 张模板；原模板另存为备份。

“Codex 已完成”不等于“图片已经替换”。如果页面仍显示“Codex 处理中”“需要处理”或“替换失败”，发布包继续使用本地模板。

遇到以下情况时按页面提示保留模板：

- ImageGen 额度不足；
- Codex 没有生成文件；
- 文件不是可完整解码的 PNG；
- 图片尺寸异常；
- 产物与原模板哈希相同；
- 文件不在当前商品的版本目录；
- 安全替换失败。

每张案例图仍需人工看一眼：不得包含客户隐私、商标、水印、伪造平台界面、虚构评价或无法证明的效果承诺。

## 二、配置百度网盘（可选）

工作台只使用百度官方 OAuth 和文件上传接口。需要先在百度开放平台创建应用，取得 App Key 和 Secret，并把工作台显示的本地回调地址登记为授权回调地址。

1. 打开“设置与安全”。
2. 在“百度网盘（可选）”中填写 App Key 和 Secret 后保存。
3. Secret 保存后会立刻从输入框清空，工作台不会回显 Secret、访问令牌或刷新令牌。
4. 点击“开始百度授权”，在新开的百度官方页面由你本人登录并同意。
5. 回到工作台确认状态显示“已授权”。

没有开放平台配置时不要填写普通百度账号密码。工作台不需要、也不会保存百度账号密码、短信验证码或浏览器 Cookie。

## 三、大文件交付

标准交付仍优先使用闲鱼页面当前支持的附件。附件能力未完成真实校准或文件过大时：

1. 在订单页先生成并校验 ZIP 交付包。
2. 已配置百度 OAuth 时，人工确认后上传交付包。文件按 4 MiB 分片计算 MD5、预创建、分片上传并合并，上传期间文件变化会立即停止。
3. 个人百度账号不保证拥有自动创建分享链接的官方权限。无法自动分享时，任务会进入“等待粘贴链接”。
4. 在百度网盘中由你本人创建分享链接，把 HTTPS 链接粘贴回订单页，再准备发送审批。
5. 闲鱼中的发送动作仍需当前可见订单目标、校准阶段和当次审批三层闸门；百度上传成功不会自动向买家发消息。

## 四、清除配置

在设置页执行“清除百度配置”会要求二次确认。清除后工作台停止新的百度上传，已有闲鱼交付记录和本地 ZIP 不会被删除；百度网盘中已经上传的文件需要你在百度网盘内自行管理。

## 五、当前实机边界

本地模板、ImageGen 验真、OAuth state/PKCE 校验、官方主机白名单、分片上传、超时和脱敏均有隔离自动测试。没有你的百度开放平台应用信息，本项目不会尝试真实百度授权或上传；个人账号自动分享也不作为交付承诺。
