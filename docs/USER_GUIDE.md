# 使用手册

## 1. 第一次打开

双击桌面的“启动简作闲鱼工作台”，桌面壳会同时启动本地服务并常驻系统托盘。设置 6–12 位数字 PIN。PIN 用于解锁工作台、派生敏感设置密钥和加密备份。正式数据目录是项目下的 `data`，浏览器登录资料单独保存在 `data/browser-profile`。关闭窗口只会隐藏到托盘；需要完全停止时使用托盘菜单或桌面的停止快捷方式。

## 2. 准备商品

在“商品库”选择商品，进入“内容工厂”生成版本。24 个首发商品分别维护自己的服务范围、材料、案例说明和交付检查。系统会创建三个标题候选、白描详情、三档价格、材料清单、FAQ、交付规则和六图。案例图先生成按商品区分的本地示意，可再由 Codex ImageGen 重做；含中文、价格和流程的五张图由本地模板渲染。

## 3. 模拟发布

在“发布中心”选择内容就绪商品，连接器选择“模拟闲鱼”。提交后动作进入人工审批；批准后，Worker 在排期时间执行。可以打开“模拟结果未知”验证停机和禁止重放。

## 4. 客服

“消息客服”先按固定规则判断意图，再生成回复。议价最多 10%，材料不齐会追问。退款、投诉、验证、违规需求和范围不清会暂停 AI。

## 5. 订单与交付

订单按状态机推进。客户文件送给 Codex 前，先展示数据处理告知并记录单独同意。数字商品使用固定目录打包并生成 SHA256SUMS；远程服务只记录授权、时间、动作摘要和结果。

## 6. Codex

“Codex 任务中心”使用本机 `codex app-server --stdio`。店铺、商品和定制订单分别使用持久线程。Codex 不能直接操作闲鱼；它只能提交建议或结构化动作提案。

## 7. 紧急停止

左下角和“设置与安全”都可以触发全局停止。停止后 Worker、Outbox 和扩展不再进行新写操作，但数据和只读页面保留。恢复不会重放结果未知动作。

## 8. 经营分析

经营分析把真实记录、扩展可见页面快照和演示数据分开显示。扩展只读取当前页面正常显示的数字；没有真实数据时保持为零或空，不估算曝光。点击“生成今日日报”会保存当天的本地报告，同一天再次生成会更新原报告。
