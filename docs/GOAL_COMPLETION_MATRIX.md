## 当前唯一正确的真实校准顺序

1. 用户解锁工作台并确认绑定当前可见账号。
2. 选择一件低风险测试商品，只填写真实发布草稿。
3. 用户核对六图、标题、详情、价格与许可证后，单独决定是否发布这一件。
4. 使用受控测试买家校准一条 FAQ，不使用首位普通真实买家。
5. 进入同一受控买家的卖家订单，校准唯一订单目标和金额。
6. 先模拟交付，再制作固定数字包，最后由用户批准一次受控真实交付。
7. 观察重启恢复、重复发送保护和六类高风险停机后，才能逐步放量；退款永远人工执行。

在第 1–6 步完成前，系统不宣称“真实账号除退款外全自动运营已经完成”。
